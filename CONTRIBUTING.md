# Contributing - المساهمة

Thank you for your interest in contributing to Voice Translator!
شكراً لاهتمامك بالمساهمة في مشروع Voice Translator!

## How to Contribute - كيف تساهم

### 1. Fork the Repository

1. Go to the repository page
2. Click the "Fork" button
3. Clone your fork locally

### 2. Create a Branch

```bash
git checkout -b feature/your-feature-name
```

### 3. Make Changes

- Follow the existing code style
- Add comments for complex logic
- Update documentation if needed

### 4. Test Your Changes

```bash
# Test Backend
cd backend
python -m pytest

# Test Frontend
cd frontend
flutter test
```

### 5. Commit and Push

```bash
git add .
git commit -m "Add your feature description"
git push origin feature/your-feature-name
```

### 6. Create a Pull Request

1. Go to the original repository
2. Click "New Pull Request"
3. Select your branch
4. Add description of changes
5. Submit the pull request

## Code Style - نمط الكود

### Python (Backend)

- Follow PEP 8 guidelines
- Use meaningful variable names
- Add docstrings to functions

### Dart (Frontend)

- Follow Dart style guide
- Use meaningful widget names
- Keep widgets small and focused

## Reporting Issues - الإبلاغ عن مشاكل

1. Check if the issue already exists
2. Create a new issue with:
   - Clear title
   - Steps to reproduce
   - Expected behavior
   - Actual behavior
   - Screenshots (if applicable)

## Questions? - أسئلة؟

Feel free to open an issue for any questions!
لا تتردد في فتح issue لأي أسئلة!
